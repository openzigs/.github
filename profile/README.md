# OpenZigs

OpenZigs makes open-source software you run yourself. There are two projects, each free and
developed in the open on GitHub.

### [On Your Left](https://openzigs.com/on-your-left/)

A free, open alternative to Strava + Zwift for cycling: ride tracking, smart-trainer control and
live Bluetooth sensors, on Android and in Chrome or Edge. AGPL-3.0-or-later.

- Site: [openzigs.com/on-your-left](https://openzigs.com/on-your-left/)
- Repository: [openzigs/onyourleft](https://github.com/openzigs/onyourleft)
- Try it: there is no download yet; [run the web app from source](https://github.com/openzigs/onyourleft#getting-started)
  and open it in Chrome or Edge.

### [delivery](https://openzigs.com/claude-delivery-plugin/)

A Claude Code plugin that takes a GitHub issue through implement, independent review, fix and
re-review, and stops at a reviewed pull request. MIT.

- Site: [openzigs.com/claude-delivery-plugin](https://openzigs.com/claude-delivery-plugin/)
- Repository: [openzigs/claude-delivery-plugin](https://github.com/openzigs/claude-delivery-plugin)
- Install: `claude plugin marketplace add openzigs/claude-delivery-plugin`, then
  `claude plugin install delivery@claude-delivery-plugin`.
